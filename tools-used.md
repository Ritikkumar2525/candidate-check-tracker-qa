# Tools Used

- **Node.js / npm**: To run the project and install test dependencies.
- **Jest**: The primary testing framework used to write the automated assertions and run the test suite.
- **Supertest**: Used alongside Jest to mock HTTP requests to the Express.js API and test the endpoints directly without a running network server.
- **Regex & File System (fs)**: Used to read the HTML/JS source code and write assertions to detect UI rendering and logic bugs without needing a full browser automation suite.
